# Roadmap

## Current foundation

**Being qualified:**

- native documentation;

**Domain capabilities and claims:** empty.

## Capability milestones

1. **The three v1 record schemas with golden fixtures** (`run_plan`, `run_observation`, `design_step_learning_record`), each with strict typing, docs and coverage.
2. **Deterministic DAG validation and no-model reference dispatch** over registered operation profiles.
3. **Crash quarantine, two-stage cancellation and post-merge re-verification** for concurrent design branches.
4. **Design-step learning-record emission and seven-cause withdrawal lineage hooks** against sealed-custody interfaces.

**Enrolled with every implementation change:**
- strict native typing and linting;
- native documentation;
- meaningful statement and branch coverage;
- affected boundary tests and benchmarks.

**Requires its own evidence and explicit approval:**
- activating AI-assisted flow steps;
- any off-premises compute dispatch;
- public activation and release.

No availability date is promised. No performance, yield or productivity gain is promised either.
